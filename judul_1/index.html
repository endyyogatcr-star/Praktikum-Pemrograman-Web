Informasi Sistem

Aplikasi web ini merupakan media pengelolaan data mahasiswa berbasis web yang dibuat sesuai standar HTML5.

Fitur Utama Sistem

Sistem ini dilengkapi dengan tampilan tabel data mahasiswa, form registrasi, serta navigasi semantik.

Form Tambah Data Mahasiswa

Gunakan form berikut untuk menambahkan data mahasiswa baru ke dalam sistem:

Formulir Registrasi Mahasiswa



Masukkan NPM angka 8 hingga 12 digit.



Panjang nama antara 3 hingga 100 karakter.



Pilih program studi mahasiswa.



Rentang tahun angkatan antara 2018 hingga 2026.



Gunakan format email yang valid.
